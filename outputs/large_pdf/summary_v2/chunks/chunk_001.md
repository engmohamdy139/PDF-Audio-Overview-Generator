### Summary

This section provides background on sequence transduction models and introduces the Transformer model architecture. The authors highlight the limitations of previous models, such as the Extended Neural GPU, ByteNet, and ConvS2S, which rely on sequential computation and have increasing computational complexity with distance between input and output positions. The Transformer addresses these issues by using self-attention, which computes representations in parallel for all input and output positions, reducing the number of operations required to relate signals from any two positions to a constant number. This approach is contrasted with models that use recurrent neural networks (RNNs) or convolutional neural networks (CNNs), and it is noted that the Transformer is the first transduction model to rely entirely on self-attention.

The Transformer architecture is described in detail, following the encoder-decoder structure common in competitive models. Each layer in both the encoder and decoder consists of two sub-layers: a multi-head self-attention mechanism and a position-wise, fully connected feed-forward network. These sub-layers are connected via residual connections, which are followed by layer normalization. The authors emphasize the importance of these normalization layers in stabilizing the training process.

The encoder and decoder stacks are described in more detail. The encoder is composed of N = 6 identical layers, each containing two sub-layers: a multi-head self-attention mechanism and a feed-forward network. The decoder also has N = 6 identical layers, with an additional sub-layer that performs multi-head attention over the output of the encoder stack. The authors note that the self-attention mechanism in the decoder is modified to prevent positions from attending to subsequent positions, ensuring that predictions for a given position can only depend on previously known outputs.

In summary, the Transformer model architecture is designed to efficiently compute representations of input and output sequences using self-attention, which reduces computational complexity and allows for effective learning of dependencies between distant positions.
